## Retroactive creation note

`docs/architecture/repository-topology.md` in `aegisos-foundation` specifies
creating `aegisos-manifest` *before* the first source sync. The first sync
already completed (2026-07-30) before this repository existed. This
repository is therefore created retroactively, after the sync and the
primary emulator build, with owner approval recorded in ADR-017. It contains
only the pinned manifest export, this provenance record, and an empty
overlay boundary — never a copied source tree, build output, or secret
material.
